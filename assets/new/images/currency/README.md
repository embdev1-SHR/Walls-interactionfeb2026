# Photos of real Indian money — taken at the centre

Coins and Notes uses a real photo of each coin and note when it is here, and a
drawing until then. Freely licensed photos of single, current Indian coins and
notes do not exist online, so these are best taken by the centre.

Photograph each one flat, on a plain white sheet, filling the frame, in good
light. Save as JPG with exactly these names:

    coin-1.jpg   coin-2.jpg   coin-5.jpg   coin-10.jpg
    note-10.jpg  note-20.jpg  note-50.jpg  note-100.jpg

Rebuild the installer and the photos appear in the activity.
